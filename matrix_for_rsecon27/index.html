Why Matrix?

  • Open & decentralised – like e-mail: an account on any server can talk to any other
  • You sign up on matrix.org, our space lives on epfl.ch – and that just works
  • End-to-end encrypted direct messages and private rooms
  • Apps for phone, web and desktop – use them all at the same time
  • Stays with you after the conference: one account for the whole RSE community

In a nutshell

  1. Create a matrix.org account – easiest with GitHub
  2. Install Element X on your phone (or use Element on the web)
  3. Save your recovery key
  4. Scan the QR code and join the RSECon27 space
Each step is explained in detail on the following slides.

2 · Create your matrix.org account

  • No GitHub? Username + password + e-mail works too
  • GitHub is the most straightforward – but for more sovereignty, choose (yet another) username + password

Remember: you log in with GitHub

  • Your account has no Matrix password
    → on every new device, choose “Continue with GitHub” again
  • GitHub is not your encryption key – you still need the recovery key (next step)
  • Add an e-mail address to your account (step 5) – your fallback if you ever lose GitHub access

Alternative: without GitHub

Choose username + password, confirm your e-mail and solve the captcha
GitHub is the most straightforward, but for more sovereignty this is of course the better choice – (yet another) username + password.

5 · Set up your profile

  • Avatar – a photo helps finding each other at the conference

7 · Add your second device

  • Sign in on the other device, with “Continue with GitHub” again
  • Then verify the new device:
    • scan a QR code with the device you already use, or
    • enter your recovery key
  • Without verification: “Unable to decrypt message”

8 · Troubleshooting

  • “Unable to decrypt” → verify this device (step 7)
  • No notifications → check OS settings for Element X / your browser
  • Can't log in → did you use “Continue with GitHub”? There is no password
  • Lost the recovery key while logged in → create a new one in settings (Encryption).
    Lost it and all devices → old encrypted messages are gone, the account is fine
  • Can't find the space → open the QR code / link again
